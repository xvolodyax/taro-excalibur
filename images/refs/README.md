# Референсы лиц — ТАРО СЕЙЧАС

Cover работает в режиме `host_reference`. На обложках **только Виктория**.
Алёну сюда не класть и в `input_urls` не ставить.

Канон лица в git:

```text
memory/cover/assets/виктория.png
```

`input_urls` в `blog-hero.json` = этот файл.

## Что даёт реф

- лицо Виктории
- глаза в промтах: зелёные + слегка светло-карие у зрачка, **даже если** лист читается как карий
- волосы: блонд, тёмные корни, пробор посередине

Реф **не** костюм. Не копировать камисоль, голубые джинсы, белые кеды, золотую подвеску-дерево.
