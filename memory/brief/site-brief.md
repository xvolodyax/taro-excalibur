Не источник prose для Writer (Writer = master prompt + research + titles-only).

## Сайт

- **site_name:** ТАРО СЕЙЧАС
- **site_url:** `{{SITE_BASE}}` в git-артефактах статей; публичный бренд: `https://www.таросейчас.рф/`
- **language:** ru
- **обращение:** «ты», женский род (пишем женщине)
- **niche:** таро для женщин 20–50; около 78% тем — отношения. Читательница покупает доступ к голове человека, которого нельзя спросить. Не обещать «прочитать мысли».

- **выход контента:** статьи в Дзен. WordPress publish выключен.

## Главный герой визуала

- **cover_mode:** `host_reference`
- **канон лица (навсегда):** `shared/cover-host-canon.md` + `shared/SOUL.md` (раздел Visual)
- **на обложке статьи Виктория всегда в кадре**, по рефу. Алёна может быть в тексте как лицо бренда; на картинки и в i2i не ставить.
- **реф только** `memory/cover/assets/виктория.png` (алиас `victoria.png`). Длинные прямые светлые волосы, радужка светло-зелёная с лёгким hazel у зрачка (**не карие глаза**), то же лицо. Лицо к камере, чтобы зелёный читался. Не брюнетка, не двойник, не Алёна, не шов по лицу.
- **натюрморт без неё** — только инлайн внутри статьи, никогда не cover.
- **сверка:** после каждой генерации открыть реф и кадр рядом. Волосы / глаза / кость не те или шов — пересобрать весь холст, в пакет не класть.
- **генерация:** Kie.ai GPT Image 2, i2i с этим рефом; `prefer_local_reference` + File Upload. Одна billed-генерация на first-try; identity-fail (нет лица / чужое лицо / шов) — HARD reject, новый холст. Beauty-redo запрещён.
- **обложка:** лицо и глаза по рефу + хук 2–6 слов (часть композиции, не H1 статьи; образец ритма «Пауза или конец?»). Одежда и эмоция **каждый раз новые** — реф не костюм (не копировать белый пиджак, камисоль, голубые джинсы, золотую подвеску-дерево, карты в руках).
- **подпись кодом** точно: `Виктория - таролог команды «ТАРО СЕЙЧАС»`. Модель строку не рисует.
- **кто рисует:** только агент Cover. Холл обложки больше не перерисовывает.
- **reference / lock:** `memory/cover/blog-hero.json` + `memory/cover/assets/`
- **input_urls:** только `виктория.png` / `victoria.png`. Алёну не ставить. Публичный URL после заливки — только `{{SITE_BASE}}/wp-content/...` в `reference_url_hosted`. Не catbox, не localhost, секреты не писать.
- **style:** `memory/cover/cover-design-code.json` + `memory/cover/quad-style-taro-seichas.json`
- **холст:** **2K**, **2×2**, резка: обложка + 2–3 inline. **1K** только если кадр один и не режется. Cover-only redo лица — 16:9 2K, инлайны можно оставить.
- **inline:** без лиц и без людей; смысл / схема / вопрос. Типы: `memory/cover/inline-visual-types.json`
- **палитра:** белый воздух `#FFFFFF`, чернила `#1A1414`, тёплый акцент бордо / терракота / пыльная роза `#8B3A3A`. Не неон-розовый коллаж, не готика.
- **запрет:** одно белое худи на все кадры; мемные стикеры; скотч-коллаж; слово «лох»; тёмный стол, свечи, готика.
- **`meme_caption_ru`:** пустой
- **Дзен:** готовый файл с диска; никогда localhost / 127.0.0.1
- **рефы лиц в git:** `memory/cover/assets/виктория.png` (`status: READY`, `assets_status: present`). Не выдумывать `reference_url_hosted`.
