# Site brief — ТАРО СЕЙЧАС

Метаданные сайта и контент-стратегия для Cover / Scout / Publish.
Не источник prose для Writer (Writer = master prompt + research + titles-only).

## Сайт

- **site_name:** ТАРО СЕЙЧАС
- **site_url:** `{{SITE_BASE}}` в git-артефактах статей; публичный бренд: `https://www.таросейчас.рф/`
- **language:** ru
- **обращение:** «ты», женский род (пишем женщине)
- **niche:** таро для женщин 20–50; около 78% тем — отношения. Читательница покупает доступ к голове человека, которого нельзя спросить. Не обещать «прочитать мысли».
- **Дзен:** канал / студия `todaytaro_bot` — `https://dzen.ru/todaytaro_bot`
- **выход контента:** статьи в Дзен. WordPress publish выключен.

## Редакция

- **формат:** короткая сцена → ловушка → ясность → один шаг. Не энциклопедия «что такое таро». Не how-to про соцсети.
- **канон:** `shared/pipeline-canon.json`
- **стиль:** `shared/article-style.md` + `shared/SOUL.md` + `shared/dzen-content-rules.md`
- **темы:** Scout → Wordstat + сигнал ниже. `memory/topics/` запрещена.
- **Главред на статьи не нужен.** Sol + гейты плагина. Главред только для постов каналов (вне этой репы).

## Главный герой визуала

- **cover_mode:** `host_reference`
- **на обложках только Виктория.** Алёна может быть в тексте как лицо бренда; на картинки и в i2i не ставить.
- **глаза (жёсткий маркер):** зелёные + слегка светло-карие у зрачка; не карие, не серые, не голубые.
- **reference / lock:** `memory/cover/blog-hero.json` + `memory/cover/assets/`
- **input_urls / локальные файлы:** `memory/cover/assets/victoria-face.jpg`, `victoria-sheet.png` (коллаж ~12 кадров), `victoria-character-sheet-2k.png` (лист 8 кадров). Копии можно держать в `images/refs/`. Алёну в `input_urls` не ставить. Публичный URL после заливки — только `{{SITE_BASE}}/wp-content/...` в `reference_url_hosted`. Не catbox, не localhost, секреты не писать.
- **style:** `memory/cover/cover-design-code.json` + `memory/cover/quad-style-taro-seichas.json`
- **генерация:** Kie.ai GPT Image 2; одна billed-генерация; **2K**, холст **2×2**, резка: обложка + 2–3 inline. **1K** только если кадр один и не режется.
- **обложка:** лицо и глаза по рефу + хук 2–6 слов (образец ритма «Пауза или конец?»). Одежда и эмоция **каждый раз новые** — реф не костюм (не копировать белый пиджак, камисоль, голубые джинсы, золотую подвеску-дерево, карты в руках).
- **inline:** без лиц и без людей; смысл / схема / вопрос. Типы: `memory/cover/inline-visual-types.json`
- **палитра:** белый воздух `#FFFFFF`, чернила `#1A1414`, тёплый акцент бордо / терракота / пыльная роза `#8B3A3A`. Не неон-розовый коллаж, не готика.
- **запрет:** одно белое худи на все кадры; мемные стикеры; скотч-коллаж; слово «лох»; тёмный стол, свечи, готика.
- **`meme_caption_ru`:** пустой
- **Дзен:** готовый файл с диска; никогда localhost / 127.0.0.1
- **рефы лиц в git:** путей канон задан, бинарников в этом прогоне нет (`NEED_MORE_REFS` / `assets_status: need_upload`). Пока файлов нет — Cover i2i не запускать. Не выдумывать `reference_url_hosted`.

## Scout / Wordstat

- Темы из Яндекс Вордстата. `folderId` каталога (не ключ): `b1g0a71ifv910gjalmhp`
- API-ключ Wordstat не хранить в репе
- Живой сигнал (смысл, не копипаст чужой подачи): пауза; что он чувствует; вернётся ли; написать первой; смотрит истории
- **Не брать как новую жвачку:** «он не пишет», «дата рождения» (уже были на Дзене)
- Лучший крючок-образец: «Пауза или конец?»
