# Voice inbox — ТАРО СЕЙЧАС

Дата сырья: 2026-08-27. Setup не копирует чужие посты дословно в будущие статьи.

## Зачем этот Setup Voice

Прошлый текст был водяным. Каркас эталонов ок, **слог ещё надо сделать живее**.
Это главная задача. Writer = смысл. Sol = слог. После Sol прозу не переписывать.

## Желаемый слог Sol

- Живой «ты», женский род.
- Простые слова. Если фразу надо объяснять — выкинуть.
- Глубина за счёт **одной конкретной сцены**, не поэзии и не метафор «про тишину».
- Старт: живая сцена. Не название механики («карта дня», «личное число года») и не «в этой статье разберём».
- Одна сцена, один чат, одна ловушка.
- Абзац, который ничего не двигает, вылетает.
- Без тройного пересказа одной паузы (не три абзаца про одно и то же молчание).
- Без штампов: «давай честно», «знакомо», «представь», «в современном мире», «как известно».
- Не гладить голос под SEO. Никаких хвостов в H1 и в лиде.
