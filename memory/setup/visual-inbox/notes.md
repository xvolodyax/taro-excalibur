## Visual lock с рефа

Студийный портрет, светлый high-key белый фон. Без свечей, без тёмного стола, без готики.

- волосы: длинные прямые платиновый блонд, прямой пробор, по плечам;
- глаза: миндалевидные, **зелёные + слегка светло-карие / hazel у зрачка**;
- брови: тёмно-коричневые, ухоженные; чёрная стрелка;
- тон: тёплый загар, профессиональный контур, приглушённая розово-mauve помада;
- серьги: маленькие сверкающие гвоздики;
- одежда на рефе: белый приталенный блейзер с широкими лацканами и золотыми пуговицами у манжеты, белый топ — это **реф лица**, не lock одежды;
- в руках на рефе две карты Rider-Waite (The Lovers, The Hierophant) — реквизит рефа, не обязателен на каждой обложке.

## Правила обложки

- лицо = Виктория по рефу; **эмоция и одежда каждый раз новые**;
- хук **2–6 слов** на кадре, не заголовок статьи;
- холст 2K 2×2, резка по белым швам;
- inline / текст панелей: **без лица**;
- подпись **кодом** (не рисовать нейросетью): `Виктория - таролог команды «ТАРО СЕЙЧАС»`;
- Алёну на обложки **не** ставить;
- не тёмный стол со свечами; эстетика чистая, яркая, business-chic («Kie»);
- провайдер: **Kie GPT Image 2** (i2i);
- если лицо не Вики или шов кривой — **пересобрать холст**, не чинить лицо снаружи.

## Палитра (ориентир)

- фон: `#FFFFFF` (чистый белый, не beige);
- ink: `#141821`;
- акцент: сдержанное золото / тёплый nude, не розовый cat-коллаж пайплайна и не gothic purple.
